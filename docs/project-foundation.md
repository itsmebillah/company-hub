# Project Foundation

Company Hub began as a Next.js 15 App Router foundation and has grown into a full internal operations portal. The current platform uses TypeScript, React 19, Tailwind CSS 4, shadcn-compatible primitives, Lucide icons, next-themes, Supabase PostgreSQL/Auth/Storage/Realtime, PWA metadata/service worker, ESLint, and Prettier.


For current status and constraints, use [PROJECT_STATE.md](../PROJECT_STATE.md), [ARCHITECTURE.md](../ARCHITECTURE.md), and [PRODUCT_REQUIREMENTS.md](../PRODUCT_REQUIREMENTS.md).
